# 검증 기록

검증일: 2026-10-11. 실행 환경: 사용자 Mac (arm64), Python 3.12.14 가상환경, SQLite, 실제 Uvicorn HTTP 서버, Codex 내장 브라우저. 운영 데이터와 분리한 임시 SQLite DB를 사용했습니다.

## 완료

- Mac에서 `pytest -q`: **27개 통과** (실제 HTTP 업로드 클라이언트 테스트 포함)
- `node --test tests/test_ui.cjs`: **3개 통과** (상세 화면 탐색 갱신, 업로드 옵션 일관성, 중단 건수 표시)
- 자동/수동 multipart 업로드, 정상 완료 Finding 0건, 실패/중단 검증
- 같은 실행 ID 재전송 및 다른 내용 충돌, 실제 재검사 실행 분리
- 잘못된 분류/시각/파일명/UTF-8/빈 파일/크기/중복 파일명 거부와 원자적 등록
- 한글 제목, UTF-8 BOM/CRLF 원본 바이트 보존, HTML/위험 링크/외부 이미지 처리
- 상태 동시 수정 revision 충돌과 작성자·댓글·변경 전후 값 이력
- 정상 완료/실패 집계 분리, 오탐률·검토율 분모, CL별 최신 실행, 필터/페이지, CSV 수식 방지
- 실제 Uvicorn HTTP 서버와 표준 라이브러리 업로드 클라이언트 통신: 한글 MD, 재전송, 409, 0건, 실패
- 초기 설정 재실행 시 비밀번호/토큰 유지 및 0600 파일 권한
- PostgreSQL psycopg 드라이버 로딩 및 SQL dialect 컴파일
- JavaScript syntax (`node --check`), shell syntax (`bash -n`), Python 컴파일
- 운영/테스트 Compose YAML 파싱

테스트 도구에서 Starlette의 httpx 호환 경로에 대한 deprecation warning 1개가 발생했습니다. 테스트 실패는 없습니다.

## Mac 브라우저 검증과 수정

- 빈 초기 화면에서 정상 완료 0건 실행과 예제 MD를 수동 등록했습니다.
- MD의 한글 제목·표·코드 블록을 열람하고, 실제 결함/진행 중/담당자를 저장했습니다.
- 댓글과 변경 전후 이력을 확인하고 새로고침 후 보존을 확인했습니다.
- 상세 화면/직접 Finding 링크에서 왼쪽 탐색이 비어 있거나 이전 범위로 남는 문제를 수정했습니다. 업로드 직후 CL 실행 건수가 즉시 갱신되는 것을 확인했습니다.
- Finding 없음 선택 시 파일 선택을 비활성화하고 선택 파일을 해제합니다. 실패/중단 전환 시 0건 정상 완료 체크를 해제·비활성화합니다. 브라우저에서 0건 체크 후 중단으로 전환하여 정상 등록되는 것을 확인했습니다.
- 요약 카드에 누락됐던 중단 실행 수를 표시합니다. 전체 집계는 실행 3/Findings 1/실제 결함 1, CL별 최신 집계는 최신 중단 실행 1/Findings 0/비율 —로 확인했습니다. 이전 실행 이력은 그대로 남았습니다.
- 브라우저 console 오류/경고는 없었습니다. 데스크톱 화면 렌더링을 시각 확인했습니다.
- CSV 내용·원본 MD 바이트 보존은 Python API 테스트에서 검증했습니다. 브라우저 다운로드 저장과 모바일 화면은 이번 검증에 포함하지 않았습니다.

## 운영 서버의 다음 검증

1. 사내 프록시와 저장소 설정 후 `scripts/install.sh --port 9999`.
2. `scripts/manage.sh test`로 운영 DB와 분리된 PostgreSQL 17 컨테이너 통합 테스트.
3. 웹 수동 등록: MD 1개 / 정상 완료 0건 / 실패 실행을 각각 등록.
4. MD 열람, 담당자·판단·수정 진행·댓글 변경과 통계/CSV 확인.
5. 스캔 장비에서 `scripts/upload.py`로 등록 후 같은 ID 재전송 중복 방지 확인.
6. 백업 후 별도 검증 서버에서 복원하고 MD·상태·이력 확인.

## PKG 레이어 탐색 UI 후속 검증 (2026-10-11)

- 왼쪽 메뉴를 검사 결과/통계/결과 등록으로 고정했습니다. 첫 화면에는 PKG 버전 카드만 표시하고, 브랜치 → 파트 → CL을 선택한 뒤 해당 CL 실행 이력을 표시합니다.
- 통계는 별도 화면으로 이동했습니다. 현재 버전·브랜치·파트 필터를 이어받고 전체 보기/필터 적용/전체 및 최신 집계/CSV를 제공합니다.
- 단계별 범위와 통계 집계 모드를 URL에 보관하여 새로고침해도 유지합니다. 기존 Run/Finding 직접 링크를 보존합니다.
- 실제 브라우저에서 버전부터 Finding까지 클릭, 기존 검토 정보와 댓글 보존, 상단 경로 복귀, 통계 필터 변경·초기화, 최신 집계 새로고침, 왼쪽 결과 등록 버튼을 확인했습니다.
- 현재 브라우저 폭에서 왼쪽 메뉴와 버전 카드 레이아웃을 시각 확인했습니다. 480px 이하에서는 메뉴를 상단으로 배치합니다.
- UI 회귀 테스트 **6개 통과**: 계층별 요청 범위, 통계와 실행 이력 분리, CSV 필터, 늦게 도착한 응답의 화면 덮어쓰기 방지, 상세 링크와 업로드 옵션.

- 전체 Python 테스트 **39개**, UI 회귀 테스트 **7개** 통과. 기존 Starlette httpx deprecation 경고 1개는 남아 있습니다.

- 실제 브라우저: Won’t fix 및 False positive 종료, 수정 CL 없을 때 Fixed 저장 차단, CL 123789로 Fixed 저장, 새로고침 보존, 재오픈 시 CL 해제·상태 이력, 목록의 Closed/Fixed/CL 표시, 통계의 Open 0/Closed 1을 확인했습니다. 브라우저 console 오류/경고는 없었습니다.
- 실제 PostgreSQL의 ALTER/잠금 실행과 Docker 빌드는 서버 준비 후 검증해야 합니다. Linux 배포는 수행하지 않았습니다.
